# tessel

A keyboard-first tiling window manager for macOS.

tessel is an experiment. It grows one feature at a time: each feature starts
behind a config flag, gets used for real, and is then kept or removed. It aims
to stay fast and light, so it only gains what it actually needs.

## Status

Nothing to install yet. The [roadmap](https://github.com/taecontrol/tessel/issues)
lives in the issues, and [docs/features.md](docs/features.md) compares the
window managers that inspired it and tracks which ideas are planned.

## Requirements

- Apple silicon
- macOS 27 or later
- The Accessibility permission
